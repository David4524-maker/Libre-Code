## ¿Qué es LibreCode?

**LibreCode** es una aplicación de escritorio que reúne **14 lenguajes de programación**
en una sola interfaz con:

-  Editor central con plantilla inicial para cada lenguaje.
-  Botón **Ejecutar (F5)** que compila/e interpreta y muestra el resultado al instante.
-  Panel de salida a la derecha con el resultado formateado.
-  Guardado rápido con `Ctrl+S`.
- Interfaz de 3 paneles: **lista de lenguajes** · **editor** · **resultado**.

## Lenguajes soportados

| Lenguaje | ¿Requiere instalación externa? | Motor utilizado |
|---|---|---|
| **Python** | No | `sys.executable` (intérprete de IDLE) |
| **HTML** | No | Se abre en el navegador |
| **CodePen** | No | Se abre en el navegador |
| **SQL** | No | `sqlite3` en memoria (incluido en Python) |
| **Malbolge** | No | Intérprete propio en Python puro 🧠 |
| **Terminal** | No | CMD (Windows) / bash (Linux/macOS) |
| **JavaScript** | Sí | Node.js |
| **TypeScript** | Sí | `tsc`, `ts-node` o `deno` |
| **C** | Sí | `gcc` |
| **C++** | Sí | `g++` |
| **C#** | Sí | `csc`, `mcs` o `dotnet` |
| **Java** | Sí | `javac` + `java` |
| **Go** | Sí | `go` |
| **Rust** | Sí | `rustc` |

> **6 lenguajes funcionan desde el primer segundo** sin instalar nada.
> Los otros 8 se activan en cuanto su compilador esté en el `PATH`.
